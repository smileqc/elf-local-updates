# 精灵手机单机版：登录下载

本仓库为私有更新仓库。只有被授权的 GitHub 账号可下载客户端、资源和运行包。完整开发源码仍在独立私有仓库。

已有手机：覆盖安装最新精灵客户端，不卸载或清除数据。进入「存档与连接 → 登录更新下载」，保存仅本仓库 Contents 只读的 fine-grained 个人访问凭证，然后点「进入手机存档」。联网检查客户端及增量资源；断网继续已有完整版本。

新手机：登录有权限的 GitHub 账号，从 Releases 下载 elf-offline.apk。安装后设置下载凭证，进入手机存档自动下载完整资源并创建新存档。

下载凭证：GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens。Resource owner 为 smileqc；Repository access 只选 elf-local-updates；Repository permissions 中 Contents 设为 Read-only。设置有效期，不授予源码仓库、写入或管理权限。把生成的凭证只输入自己手机，不发到聊天、仓库或截图中。到期可重新生成并在手机更换。其他使用者需要拥有该私有仓库读取权限。

运行包包含手机单机所需的玩法代码，授权下载者仍可能读取或逆向。访问控制限制下载人，不保证下载后的代码绝对保密。
